OddCerta Live Monitor

Como abrir este aplicativo corretamente

Você abriu o arquivo direto do seu computador (file:///). Por ser uma aplicação moderna em React e com servidor Node.js (responsável por puxar as odds e dados da ESPN), o navegador bloqueia a execução direta deste arquivo por regras de segurança (CORS).

Passo a passo para abrir:

  1. Vá até a pasta do projeto no Windows.
  2. Dê dois cliques no arquivo iniciar.bat.
  3. O servidor iniciará e seu navegador abrirá automaticamente em http://localhost:3000.
